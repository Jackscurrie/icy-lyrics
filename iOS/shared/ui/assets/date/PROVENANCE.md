# Android 36 medium-date / short-time profiles

`android36-medium-short.json` is generated by `iOS/tests/generate_android_date_profiles.py` from the actual emulator measurement in `iOS/tests/evidence/android36-date-formats.zip`. It contains 881 locale mappings, 324 distinct pattern/symbol profiles, and two aliases explicitly covered by the Android samples. The generator verifies the archive SHA-256 and records the raw inventory SHA-256 in the JSON.

Measured platform: Android API 36, ICU 76.1, CLDR 46. The source API is `java.text.DateFormat.getDateTimeInstance(MEDIUM, SHORT, locale)`. The measured calendar is Gregorian. Patterns and symbols are preserved; profiles are deduplicated only when all four recorded fields match exactly.

The iOS adapter uses Foundation for Gregorian calendar components and timezone arithmetic, and this data for visible punctuation, month/day-period names, and digits. It does not use Foundation date styles or modify already-formatted strings. Arbitrary Unicode locale extensions, unknown locales, older Android ICU releases, historical timezone differences, and pre-Gregorian dates are not covered by the current measurement. Unknown regions use the measured language profile; unknown languages use `en`.

ICU/CLDR locale data notices are included unchanged in `ICU-76.1-LICENSE.txt`, downloaded from [the pinned ICU 76.1 source](https://raw.githubusercontent.com/unicode-org/icu/release-76-1/LICENSE). License file SHA-256: `01edac20612b1e590c1c1cfb02b7218c6adc7b0a944eda7a1e03aeee10725aed`.
