# Binary distribution review

The repository is AGPL-3.0-or-later and retains Spicy Lyrics/Icy Lyrics attribution. The shared legal assets include the existing license text and notices, plus the bundled font notices. Source modifications and build scripts must remain available with any distribution under the applicable source-license obligations.

Spotify SDK 5.0.1 is fetched from Spotify's tagged repository with a pinned SHA-256. It is not copied into source control. Spotify states that use of its developer tools accepts its Developer Terms. Its SDK binary is governed by those terms, not by this repository's AGPL license. The included MPMessagePack license must accompany SDK distribution. See [Spotify SDK terms notice](https://github.com/spotify/ios-sdk/tree/v5.0.1#terms-of-use) and [Spotify Developer Terms](https://developer.spotify.com/terms).

**Public binary release is not cleared.** The [September 4 distribution review](DISTRIBUTION-REVIEW.md) identifies the specific unresolved AGPL/SDK combination, Spotify use-case applicability, and end-user requirements. Spotify's terms permit SDK packaging in compliant applications; there is no blanket extra approval merely to create an IPA. That grant does not establish permission for this particular combined application or resolve the source-license obligations. The review separates verified notice requirements from questions needing an external decision. [Spotify iOS policy notes](https://developer.spotify.com/documentation/ios/getting-started).

Until that decision is recorded, the workflow uploads test reports and an authenticated, encrypted owner delivery. Only the public age recipient is committed; its private identity stays on the owner's Windows PC under ignored `iOS/build/owner-delivery/`. This permits the owner to retrieve the verification build without exposing a downloadable plaintext IPA. Encryption does not grant Spotify or source-license permissions.

Once the specific SDK/source-license requirements are resolved, record the decision and supporting permission or applicable terms here and set public repository variable `ICY_IOS_BINARY_DISTRIBUTION_CLEARED=true` to enable plaintext IPA artifact upload. That variable remains unset during owner delivery. No Apple membership/payment is required by that switch, and it does not bypass Spotify authorization or iPhone signing.

Release evidence must also include the corresponding source revision, dependency versions, source attribution, SDK archive checksum, bundle contents/checksum, passing simulator result, pixel-comparison results and explicit physical-iPhone status. Physical iPhone installation/refresh/Spotify tests remain pending until a tester is available.
